# BBSDoorServer
An open-source, standalone BBS door server for running legacy DOS door games independently of BBS software, with support for Mystic BBS and other systems.

## Contract prototype

See [prototype status and development](docs/prototype.md) and [session architecture](docs/architecture.md). The initial implementation validates requests and denies all launches. Drop-file generation, DOS/FOSSIL execution, transport and MysticWeb integration remain unimplemented and unverified.
