# Door Server planning hub

This folder is the **source of truth for agreed plans and open design questions** for BBSDoorServer. Update these documents when a decision changes, and keep implementation status separate from proposed features.

- [Project plan and decisions](project-plan.md) — vision, agreed boundaries, infrastructure, cross-platform direction, and decisions still to validate.
- [Shared-client architecture](shared-client-architecture.md) — Mystic and MysticWeb session flows, Door Server responsibilities, and security boundaries.
- [Implementation roadmap](roadmap.md) — ordered milestones and acceptance criteria.

**Status:** A dependency-free Node.js foundation and tests have been committed. No listening network server, DOS runtime adapter, dropfile generator, or playable game has been verified yet.
